# Coverage design

| Layer | Command |
|-------|---------|
| Jest (`packages/core/src/**`) | `yarn tests:jest-coverage` — only if `packages/core/src/` or `packages/core/plugin/` TS was touched. `packages/core/src/version.ts` is generated by `yarn prepare`; it is out of the [touched-line bar](#touched-line-bar), not a Jest config ignore. **TS ownership stays here** even after native coverage adopt. |
| Plugin TS | root `yarn tests:jest-coverage packages/core/plugin/__tests__/` (or touched plugin paths). Not `packages/core/plugin/jest.config.js`. |
| Android JVM unit | `yarn tests:android:unit` — Robolectric under `packages/core/android/src/test/` when that tree (or Robolectric wiring) changed. Harness only until product mapper tests land. |
| iOS XCTest unit | `yarn tests:ios:unit` — XCTest under `packages/core/ios/Tests/` (+ `RNGoogleMobileAdsUnitTests.xcodeproj`) when that tree changed. Podspec `UnitTests` test_spec mirrors the same sources for CocoaPods consumers. |
| E2e | [local e2e](running-e2e.md#local-e2e-commands) when [platform coverage](running-e2e.md#platform-coverage-gate-blocking) requires it |
| Native e2e (Jacoco / LLVM) | Published [`react-native-coverage@0.2.0`](https://www.npmjs.com/package/react-native-coverage) in the **example harness only** (Pattern C). See [§ native agent collection](#native-agent-collection). |

CI Codecov: Jest + e2e jobs. Review signal = **touched files**.

<a id="native-agent-collection"></a>

## Native agent collection (`react-native-coverage`)

Consume the **published** package — do **not** copy RNFB coverage scripts into this repo. Pattern C: dependency + config live under `RNGoogleMobileAdsExample/` (dedicated test app), not a shipping product `package.json`.

| Piece | Location / role |
|-------|-----------------|
| Dep | `RNGoogleMobileAdsExample` → `react-native-coverage@0.2.0` (TurboModule autolinks; New Arch only) |
| Config | `RNGoogleMobileAdsExample/react-native-coverage.config.js` (app ids, `RNGoogleMobileAds` / `react-native-google-mobile-ads` matchers; excludes Google GMA SDK) |
| Android | Example `android/build.gradle` applies package `rn-coverage.gradle` + Jacoco report helper on RNTA `:app` |
| iOS | Example `ios/Podfile` `post_install` → package `cocoapods/coverage_post_install.rb` (CocoaPods-first / static; `force_dynamic_frameworks: false`; `instrument_app: false` + app `OTHER_LDFLAGS` profile link only — avoids RNTA Swift/DevSupport break while resolving Coverage.a `__llvm_profile_*`; library prefixes + Coverage pod still get LLVM flags) |
| Flush | Appium suite teardown taps gallery **Flush coverage** (`gma.debug.flushCoverage`) → package `flush()` (Istanbul dump when Metro instrumented, then Emma/LLVM). Host: `tooling/appium` `afterSuite` → `flushCoverageFromApp()` |
| Pull / report | Package CLI `rn-coverage` (bin). Run from the example workspace so config resolves. |

**Agent sequence after a device Appium run** (session still had flush before teardown):

```sh
# From repo root — example cwd so react-native-coverage.config.js resolves:
yarn workspace RNGoogleMobileAdsExample exec rn-coverage android pull
yarn workspace RNGoogleMobileAdsExample exec rn-coverage android report
# iOS (set --device to the simulator UDID used by the run):
yarn workspace RNGoogleMobileAdsExample exec rn-coverage ios pull --device <udid>
yarn workspace RNGoogleMobileAdsExample exec rn-coverage ios export --derived-data <path>
yarn workspace RNGoogleMobileAdsExample exec rn-coverage assert
```

Artifacts (defaults from config; adjust with CLI flags as needed):

| Platform | Raw | Report |
|----------|-----|--------|
| Android | Emma `.ec` under app files → pulled into `RNGoogleMobileAdsExample/android/app/build/…` | `jacocoTestReport.xml` under `android/app/build/reports/jacoco/` |
| iOS | `.profraw` from sim container | `coverage/ios-native/lcov.info` after `ios export` (cwd-relative to example unless `--output` set) |

Optional JS e2e Istanbul: set `RN_COVERAGE_JS=1` before Metro, then `rn-coverage js pull` / `js report` (package docs). **Do not** invent root yarn wrappers that re-implement pull/export — call the package CLI.

Allowlisted invocations: [agent command policy](agent-command-policy.md#canonical-registry) (Native coverage row). Timing contract: package [e2e timing](https://github.com/invertase/react-native-coverage/blob/main/docs/integration/e2e-timing.md) (flush in-app → pull on host → report/assert).

<a id="touched-line-bar"></a>

## Touched-line bar

New code: coverage only rises.

- Touched TypeScript in `packages/core/src/` or `packages/core/plugin/`: **100% reachable touched lines**. `packages/core/src/version.ts` is generated by `yarn prepare`; leave it out of this bar. Else [acceptable exception](change-authoring-workflow.md#acceptable-exceptions) or delete dead code. Prove with `yarn tests:jest-coverage` — native Jacoco/LCOV does **not** replace this.
- Native (`packages/core/android/**`, `packages/core/ios/**`): after [§ native agent collection](#native-agent-collection), use Jacoco XML / iOS LCOV from that path when e2e (or unit merge) produced artifacts; until a change exercises those collectors, [platform coverage](running-e2e.md#platform-coverage-gate-blocking) still decides the gate signal — e2e counts for product native changes, or `yarn tests:android:unit` / `yarn tests:ios:unit` for [harness-only](running-e2e.md#platform-coverage-gate-blocking) rows. Do not stamp 100% on an empty TS set. Do not run `yarn tests:jest-coverage` for native-only diffs. Do not invent percentages without artifacts.

<a id="coverage-evidence-package"></a>

## Coverage evidence package

**Blocking.** Required to close `review_gate` / `coverage_evidence_gate` when the diff includes `packages/core/src/` **or** `packages/core/android/` **or** `packages/core/ios/` **or** `packages/core/plugin/` TS. `packages/core/app.plugin.js`-only is `n/a` unless plugin TS changed (plugin Jest still follows [Expo plugin](validation-checklist.md#expo-plugin)). Do not use `packages/core/plugin/**` as the required-when test. Native-only still records the [platform coverage](running-e2e.md#platform-coverage-gate-blocking) signal (e2e counts and/or `yarn tests:android:unit` / `yarn tests:ios:unit`) **and**, when an Appium/native-coverage run produced them, paths to Jacoco XML / iOS LCOV from [§ native agent collection](#native-agent-collection). Write `.agents/reports/<change-id>/coverage-evidence.md` (gitignored ephemeral working file; **do not stage** it per the [documentation policy](../documentation-policy.md#durable-vs-ephemeral)). Include artifacts + timestamps; per-file % for touched TS; branch → test; every gap (fix / delete / exception). Verdict: `100% on reachable touched lines` for touched TS, or `NOT 100%` with dispositions. Do not invent native Jacoco/LLVM coverage numbers without pull/report artifacts, and do not run jest-coverage on native-only diffs. Missing package = blocking finding.
