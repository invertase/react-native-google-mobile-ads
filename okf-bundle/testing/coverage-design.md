# Coverage design

| Layer | Command |
|-------|---------|
| Jest (`packages/core/src/**`) | `yarn tests:jest-coverage` — only if `packages/core/src/` or `packages/core/plugin/` TS was touched. `packages/core/src/version.ts` is generated by `yarn prepare`; it is out of the [touched-line bar](#touched-line-bar), not a Jest config ignore. |
| Plugin TS | root `yarn tests:jest-coverage packages/core/plugin/__tests__/` (or touched plugin paths). Not `packages/core/plugin/jest.config.js`. |
| Android JVM unit | `yarn tests:android:unit` — Robolectric under `packages/core/android/src/test/` when that tree (or Robolectric wiring) changed. Harness only until product mapper tests land. |
| iOS XCTest unit | `yarn tests:ios:unit` — XCTest under `packages/core/ios/Tests/` (+ `RNGoogleMobileAdsUnitTests.xcodeproj`) when that tree changed. Podspec `UnitTests` test_spec mirrors the same sources for CocoaPods consumers. |
| E2e | [local e2e](running-e2e.md#local-e2e-commands) when [platform coverage](running-e2e.md#platform-coverage-gate-blocking) requires it |

CI Codecov: Jest + e2e jobs. Review signal = **touched files**. Native Jacoco/LCOV yarn targets do not exist yet — do not invent them.

<a id="touched-line-bar"></a>

## Touched-line bar

New code: coverage only rises.

- Touched TypeScript in `packages/core/src/` or `packages/core/plugin/`: **100% reachable touched lines**. `packages/core/src/version.ts` is generated by `yarn prepare`; leave it out of this bar. Else [acceptable exception](change-authoring-workflow.md#acceptable-exceptions) or delete dead code.
- Native (`packages/core/android/**`, `packages/core/ios/**`): until Jacoco/LCOV yarn targets exist, [platform coverage](running-e2e.md#platform-coverage-gate-blocking) decides the signal — e2e counts for product native changes, or `yarn tests:android:unit` / `yarn tests:ios:unit` for [harness-only](running-e2e.md#platform-coverage-gate-blocking) rows. Do not stamp 100% on an empty TS set. Do not run `yarn tests:jest-coverage` for native-only diffs. Do not invent Jacoco/LLVM percentages.

<a id="coverage-evidence-package"></a>

## Coverage evidence package

**Blocking.** Required to close `review_gate` / `coverage_evidence_gate` when the diff includes `packages/core/src/` **or** `packages/core/android/` **or** `packages/core/ios/` **or** `packages/core/plugin/` TS. `packages/core/app.plugin.js`-only is `n/a` unless plugin TS changed (plugin Jest still follows [Expo plugin](validation-checklist.md#expo-plugin)). Do not use `packages/core/plugin/**` as the required-when test. Native-only still records the [platform coverage](running-e2e.md#platform-coverage-gate-blocking) signal (e2e counts and/or `yarn tests:android:unit` / `yarn tests:ios:unit`). Write `.agents/reports/<change-id>/coverage-evidence.md` (gitignored ephemeral working file; **do not stage** it per the [documentation policy](../documentation-policy.md#durable-vs-ephemeral)). Include artifacts + timestamps; per-file % for touched TS; branch → test; every gap (fix / delete / exception). Verdict: `100% on reachable touched lines` for touched TS, or `NOT 100%` with dispositions. Do not invent native Jacoco/LLVM coverage numbers and do not run jest-coverage on native-only diffs. Missing package = blocking finding.
