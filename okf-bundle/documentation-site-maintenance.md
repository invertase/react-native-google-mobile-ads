# Documentation site maintenance

Single source for **user-facing documentation site** maintenance: [docs.page](https://docs.page)
content under `docs/` plus root `docs.json`, and the generated core API reference.

**Policy:** [OKF documentation and commit policy](documentation-policy.md).

<a id="docsjson"></a>

## docs.json

When adding or renaming user docs pages:

- Add or update sidebar entries in `docs.json` in the same change as `docs/**`.
- Paths in the sidebar are docs.page routes (for example `/ad-formats`), not GitHub file paths.
- Run the canonical prose and link checks owned by
  [validation checklist § lint](testing/validation-checklist.md#lint-and-formatting) and
  [§ docs.page link check](testing/validation-checklist.md#docs-page-link-check).

`docs.json` **does** use `redirects` for the IA cutover (old paths → current sidebar routes).
Treat that object as the source of truth; keep entries in sync when renaming or removing
user-facing routes. Current map: `/displaying-ads` → `/ad-formats`,
`/displaying-ads-hook` → `/ad-formats/hooks`, `/native-ads` → `/ad-formats/native`, and
`/rngma-v17-api-reference` → the generated API host. Do not invent a separate redirect-audit
procedure beyond that map.

<a id="api-reference"></a>

## Generated API reference

The core TypeScript API reference is generated by TypeDoc 0.28 from `packages/core`:

- Root `typedoc.json` owns entry points, strict warning validation, navigation, output, and the
  hosted base URL contract.
- `reference-api-readme.md` owns the landing page and public adapter-package discovery;
  `docs/reference.css` owns TypeDoc presentation.
- `.github/workflows/deploy-api-reference.yml` publishes to
  `https://invertase.github.io/react-native-google-mobile-ads/`; repository Pages source must be
  **GitHub Actions**.
- `docs.json` owns the external Reference API tab and redirects the retired curated reference
  route to the generated site.

The generated site is core-only. Public scoped mediation adapters remain discoverable from the
landing page; `packages/_template` is private and excluded. Commands and forbidden alternatives
are owned by [agent command policy](testing/agent-command-policy.md#canonical-registry);
applicability and evidence are owned by
[validation checklist § API reference](testing/validation-checklist.md#api-reference).
