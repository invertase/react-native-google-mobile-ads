# App Open Ads

App open ads are a special ad format intended for publishers wishing to monetize their app load screens.
App open ads can be closed by your users at any time. App open ads can be shown when users bring your app to the foreground.

App open ads are shown when your application launches or when users bring your application to the foreground.
To make sure you have an ad ready to display when a user opens your app, you'll want to have a reference to an ad ready to use.

That means you must preload an app open ad before you need to show the ad. That way, your app open ad is ready to show the next time the app is opened.

## Cold and warm foreground lifecycle

The controller below covers both entry paths:

- On a **cold start**, load while your launch/loading screen is visible and show only if that
  screen is still the active context when loading finishes.
- On a **warm start**, listen for `AppState` returning to `active`, then show a fresh loaded ad.
- Pass `canShow={false}` while another fullscreen ad, modal, onboarding screen, or sensitive flow
  is visible. Do not surprise the user by showing an app open ad over unrelated content.

```tsx
import { useEffect, useRef } from 'react';
import { AppState, type AppStateStatus } from 'react-native';
import { AdEventType, AppOpenAd, TestIds } from 'react-native-google-mobile-ads';

const FOUR_HOURS = 4 * 60 * 60 * 1000;
const adUnitId = __DEV__ ? TestIds.APP_OPEN : 'ca-app-pub-xxxxxxxxxxxxx/yyyyyyyyyyyyyy';

export default function AppOpenAdController({ canShow }: { canShow: boolean }) {
  const appState = useRef<AppStateStatus | null>(AppState.currentState);
  const canShowRef = useRef(canShow);

  canShowRef.current = canShow;

  useEffect(() => {
    let appOpenAd: AppOpenAd | null = null;
    let loadedAt: number | null = null;
    let loading = false;
    let showing = false;
    let pendingForegroundShow = false;
    let adUnsubscribers: Array<() => void> = [];

    const retireAd = () => {
      adUnsubscribers.forEach(unsubscribe => unsubscribe());
      adUnsubscribers = [];
      appOpenAd?.destroy();
      appOpenAd = null;
      loadedAt = null;
      loading = false;
    };

    const isFresh = () => loadedAt !== null && Date.now() - loadedAt < FOUR_HOURS;

    const showPendingAd = () => {
      if (!pendingForegroundShow) {
        return;
      }
      if (!canShowRef.current || AppState.currentState !== 'active' || showing) {
        pendingForegroundShow = false;
        return;
      }
      if (!appOpenAd || !isFresh()) {
        replaceAndLoad(true);
        return;
      }

      pendingForegroundShow = false;
      showing = true;
      appOpenAd.show().catch(() => {
        showing = false;
        retireAd();
      });
    };

    const replaceAndLoad = (showForThisForeground: boolean) => {
      if (loading) {
        return;
      }
      retireAd();
      pendingForegroundShow = showForThisForeground;
      loading = true;

      const nextAd = AppOpenAd.createForAdRequest(adUnitId);
      appOpenAd = nextAd;
      adUnsubscribers = [
        nextAd.addAdEventListener(AdEventType.LOADED, () => {
          loading = false;
          loadedAt = Date.now();
          showPendingAd();
        }),
        nextAd.addAdEventListener(AdEventType.CLOSED, () => {
          showing = false;
          // The shown instance is spent. Wait for a later foreground opportunity
          // before creating another one, so closing cannot trigger a show loop.
          retireAd();
        }),
        nextAd.addAdEventListener(AdEventType.ERROR, () => {
          showing = false;
          pendingForegroundShow = false;
          retireAd();
        }),
        nextAd.addAdEventListener(AdEventType.PAID, event => {
          console.log('App open revenue', event.value, event.currency);
        }),
      ];
      nextAd.load();
    };

    const requestForegroundShow = () => {
      if (!canShowRef.current || showing) {
        pendingForegroundShow = false;
        return;
      }
      pendingForegroundShow = true;
      if (appOpenAd && isFresh()) {
        showPendingAd();
      } else {
        // Expired inventory is destroyed and replaced; never call load() on it again.
        replaceAndLoad(true);
      }
    };

    const appStateSubscription = AppState.addEventListener('change', nextState => {
      const returnedToForeground = appState.current !== 'active' && nextState === 'active';
      appState.current = nextState;
      if (returnedToForeground) {
        requestForegroundShow();
      }
    });

    // Cold start: preload, and show on load only while the app-provided loading
    // context says a fullscreen presentation is appropriate.
    replaceAndLoad(canShowRef.current && AppState.currentState === 'active');

    return () => {
      appStateSubscription.remove();
      pendingForegroundShow = false;
      showing = false;
      retireAd();
    };
  }, []);

  return null;
}
```

`pendingForegroundShow` ties presentation to one cold- or warm-foreground opportunity. Closing an
ad retires that instance without loading or showing another one. If a loaded instance reaches the
four-hour policy window, the controller destroys it and creates a replacement instead of trying to
reload the stale object.

The example intentionally does not retry immediately after an error or no-fill. Retry at a later
lifecycle opportunity to avoid a request loop. Send `AdEventType.PAID` payloads to your
[revenue telemetry](/revenue-telemetry-and-auction-diagnostics) pipeline.

## Consider ad expiration

Google's published app open guidance uses a four-hour freshness window. Record when loading
completes and request a replacement instead of showing older inventory. If you use preload pools,
the handed-out object applies the same default through `isStaleByPolicy()`.

## Cold starts and loading screens

On a cold start, you will not already have an ad in memory. Loading can finish after the user reaches
the main UI, creating an out-of-context interruption.
Use a loading screen while app assets and the ad load, and show the ad only from that screen.
If your app has completed loading and has sent the user to the main content of your app, do not show the ad.

## Best practices

Google built app open ads to help you monetize your app's loading screen, but it's important to keep best practices in mind so that your users enjoy using your app. Make sure to:

- Wait to show your first app open ad until after your users have used your app a few times.
- Show app open ads during times when your users would otherwise be waiting for your app to load.
- If you have a loading screen under the app open ad, and your loading screen completes loading before the ad is dismissed, you may want to dismiss your loading screen after receiving the `onAdClosed` event.
