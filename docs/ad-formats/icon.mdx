<Warning>
  **Alpha (experimental).** Icon ads (`IconAd`) may change on the Next-Gen Android SDK. Gate your UI with
  `getAdCapabilities().iconAd` (`experimental` on Android Next-Gen; `unavailable` on Android classic and iOS).
</Warning>

Icon ads are a dedicated Next-Gen Android format (not the `icon` asset on [native ads](/ad-formats/native)).
Load inventory, wire your layout with {@link IconAsset} children inside {@link IconAdView}, and let the SDK
register the loaded ad when assets are ready.

## Before you start

- Use [Next-Gen Android](/next-gen-sdk) with this library's Next-Gen build.
- Complete [consent](/consent-basics) and call `mobileAds().initialize()` before `load()`.
- Use [test ads](/first-ad) in development. Create a dedicated icon ad unit in AdMob when Google provides one for your account.

## Create and load

```js
import {
  IconAd,
  IconAdView,
  IconAsset,
  IconAssetType,
  AdEventType,
} from 'react-native-google-mobile-ads';

const adUnitId = __DEV__
  ? TestIds.ICON
  : 'ca-app-pub-xxxxxxxxxxxxx/yyyyyyyyyyyyyy';

const iconAd = IconAd.createForAdRequest(adUnitId, {
  requestNonPersonalizedAdsOnly: true,
});

iconAd.addAdEventListener(AdEventType.LOADED, () => {
  console.log(iconAd.headline, iconAd.icon?.url);
});

iconAd.load();
```

## Render

```jsx
{iconAd.loaded ? (
  <IconAdView iconAd={iconAd}>
    <IconAsset assetType={IconAssetType.ICON}>
      <Image style={{ width: 48, height: 48 }} source={{ uri: iconAd.icon?.url ?? undefined }} />
    </IconAsset>
    <IconAsset assetType={IconAssetType.HEADLINE}>
      <Text>{iconAd.headline}</Text>
    </IconAsset>
    <IconAsset assetType={IconAssetType.CALL_TO_ACTION}>
      <Text>{iconAd.callToAction}</Text>
    </IconAsset>
  </IconAdView>
) : null}
```

Assign at least one asset view before the native layer calls `registerIconAd`. Standard ad events use {@link AdEventType}
(`LOADED`, `ERROR`, `IMPRESSION`, `CLICKED`, `PAID`, `OPENED`, `CLOSED` for fullscreen overlays).

## destroy

```js
iconAd.destroy();
```

## Platform notes

| Backend | Status |
| --- | --- |
| Android Next-Gen | Alpha — `IconAd` + `IconAdView` |
| Android classic | `icon-ad-unavailable` on load |
| iOS | `icon-ad-unavailable` on load |

## Not wrapped yet

- Multi-load (`IconAd.load(request, maxNumberOfAds, IconAdLoadCallback)` / `onAdLoadingCompleted`)
- `loadFromAdResponse`, signal APIs, and request-only options such as `IconAdPlacement` / `setExcludedAppIds`
