---
title: React Native Google Mobile Ads
description: Ads from AdMob or Ad Manager in a React Native app, on Expo or the React Native CLI.
---

React Native Google Mobile Ads is the AdMob module for React Native. It displays adverts to your users, served through [Google AdMob](https://apps.admob.com) or [Google Ad Manager](https://admanager.google.com).

Use it when you want those adverts from JavaScript, on Expo or on a bare React Native CLI app, instead of writing the native Google Mobile Ads integration yourself.

The module supports six ad formats: app open, banner, interstitial, rewarded, rewarded interstitial, and native.
