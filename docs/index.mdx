# Getting Started

The AdMob module allows you to display adverts to your users. All adverts are served over the Google
AdMob network, meaning a [Google AdMob account](https://apps.admob.com) is required.

<YouTube id="9qCxo0D-Sak" />

The module supports six types of Ads:

1. Full screen [App Open Ads](/ad-formats/app-open).
2. Component based [Banner Ads](/ad-formats/banner).
3. Component based [Native Ads](/ad-formats/native).
4. Full screen [Interstitial Ads](/ad-formats/interstitial).
5. Full screen [Rewarded Ads](/ad-formats/rewarded).
6. Full screen [Rewarded Interstitial Ads](/ad-formats/rewarded-interstitial).
