Ads are served through Google AdMob or Google Ad Manager, so an
[AdMob](https://apps.admob.com) or [Ad Manager](https://admanager.google.com) account is required.

## Install

A coding agent follows the same install as you. [Install with agents](/ai-agents) is the prompt. It sends the agent to Install with Expo or Install with React Native CLI, for the app you already have, and to the rules in the npm package. Request consent before you call `mobileAds().initialize()`.

There are two installs because the native setup differs. Both install this package. [Prerequisites](/prerequisites) apply to both: React Native 0.86 or newer, the New Architecture, iOS 15.1, and Android `minSdk` 24.

[Install with Expo](/installation/expo) is for an Expo app. App IDs go on the config plugin. The package has native code, so you use a development build and prebuild. Expo Go cannot run it. Every plugin key is on the [Config plugin](/config-plugin) page.

[Install with React Native CLI](/installation/react-native) is for a bare app. App IDs go in the root `app.json`. CocoaPods and the iOS build phase apply them on the next build.
